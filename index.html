restaurant Website

overview

A modern and fully responsive restaurant website designed to enhance the user dining experience online. It features an interactive interface, dynamic content, and reusable components — all tailored for performance, accessibility, and visual appeal.

Features

  • Dynamic Product listing with category filters animated and search engine
  • Form validation
  • Parallax effect on scroll
  • Javascript modules to keep code clean and well-organized
  • Animated food gallery with hover effects
  • Optimized images for fast web performance
  • Dynamic customer's reviews section
  • Responsive layout using CSS
  • Order page with a form
  • LocalStorage integration for product details
  • Interactive menu and food gallery

Technologies

HTML, CSS, Vanilla Javascript, WebAIM Accessibility Checker, LocalStorage

My Role

I designed and developed the website from scratch,focusing on a clean UI/UX and modular, scalable Javascript code. One of the main challenges I faced was displaying the selected food items on the order page after the user clicked the "Order" button. Initially, I tried adding data attributes to each button, but quickly realized that JavaScript only executes on the page where it's defined — meaning the data wouldn't automatically carry over to another page. After researching the problem through articles and videos, I discovered that localStorage could be used to persist data across pages. By saving the selected product details to localStorage when the user clicked the button, and then retrieving that data on the order page using a separate script, I was able to implement the functionality successfully. This experience deepened my understanding of cross-page data handling and reinforced the importance of using browser APIs effectively when building interactive web applications.

What I learned

Designing a restaurant website allowed me to sharpen my front-end skills. I deepened my understanding of CSS by using Grid layouts and parallax effects to create a visually appealing and responsive design. I also learnt how to build a slideshow using pure CSS which proved to be a lightweight and elegant solution without relying on JavaScript. On the JavaScript side, I grasped key concepts like the includes() method to implement dynamic product search and filtering. Moreover, I got the hang of using event delegation to efficiently manage event listeners and target elements, especially in interactive components.

ecommerce Website

overview

This eCommerce website is a responsive, modern web application built to showcase and sell men suits across various categories. It features a clean UI, smooth interactivity, and a user-focused layout designed to mimic real-world online shopping experiences. The project emphasizes performance, accessibility, and maintainable front-end architecture using modular JavaScript and reusable components.

Features

  • dedicated mockups page to showcase my design previews
  • Dynamic Product listing with category filters
  • Product detail page with images, descriptions and price
  • Add to cart, update quantity, and remove items
  • Real time cart total updates
  • Form validation
  • Responsive design for mobile and desktop
  • LocalStorage integration for cart persistance

Technologies

HTML, CSS, Vanilla Javascript, WebAIM contrast checker, Affinity photo, LocalStorage

My Role

I designed and developed the website from scratch, focusing on a clean UI/UX and modular, scalable Javascript code and ensured the site meets accessibility best practices by testing with the WebAIM WAVE tool, improving contrast, keyboard navigation, and ARIA roles. One of the main challenges I faced was building the shopping cart functionality. Understanding the logic behind adding and removing items was initially difficult, so I studied how eCommerce sites like Amazon handle cart interactions. I then translated that logic into code by learning and applying JavaScript array methods — primarily through YouTube tutorials and hands-on experimentation.

What I learned

Developing and designing this eCommerce site gave me hands-on experience with key JavaScript concepts. I strengthened my understanding of DOM manipulation and learned how to structure code using modules. Building the shopping cart from scratch helped me grasp cart logic, state updates, and user interactions. Additionally, I improved my skills in image optimization for the web, ensuring faster load times. Discovering and applying data attributes allowed me to handle dynamically injected HTML more efficiently with JavaScript — a major step forward in working with interactive content and components.
